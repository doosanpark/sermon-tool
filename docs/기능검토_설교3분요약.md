## 3. ★ 규칙만으로는 안 됩니다 — 만들어서 비교함

"네 포인트를 찾았으니 각 지점부터 30초씩 이으면 되지 않나" 를 실제로 만들어 봤습니다. **실패.**

강해설교는 **포인트 선언 → 본문 낭독 → 해설 → 적용** 순서로 갑니다.
선언 직후 30초는 거의 전부 **성경 낭독**입니다.

```
[②] 12:28 +33초  (규칙 버전)
  …책임의 방향이 바뀌는 기도의 자리였어요
  제가 6절, 7절을 읽겠습니다 이제 종이 주의 종들인 이스라엘 자손을
  위하여 주야로 기도하오며 우리 이스라엘 자손이 주께 범죄한 죄들을…
                                    ↑ 30초 중 25초가 낭독
```

6조각 버전은 "네 개의 제목 + 성경 봉독" 만 남고 **목사님 해설이 한 마디도 안 들어갑니다.**

→ **내용을 읽고 골라야 한다는 증거.** 이게 DIAMOND 가 필요한 이유입니다.

### 곁다리로 확인된 것

규칙 버전에서 **"두 번째입니다" 가 잘려 나갔습니다.** 컷을 *가장 가까운* 쉼에 맞췄더니 앞머리가 1초 먹혔습니다.
→ **시작은 앞쪽 쉼으로 당기고, 끝은 뒤쪽 쉼으로 민다.** 3분 샘플은 그렇게 만들었습니다.

## 4. 논문 판정 — 지난 검토에서 하나 바뀜

### DIAMOND — **본체**

"긴 녹화에서 중요한 순간 K개를 골라 타임코드로 클립을 뽑아 잇는다" = 지금 한 일 그대로.
3단 구조도 맞습니다: 후보를 좁히고(선언 지점·쉼) → 내용으로 점수 매겨 고르고 → 길이·선호에 맞춰 확정.

특히 **수치 신호가 후보를 좁히고 LLM 은 그 안에서 고르게** 하는 부분.
여기서는 네 포인트 선언 문장이 그 수치 신호 역할을 합니다.

### NexusSum — **일부만**

지난 검토에서 "필요 없음" 이라 한 건 *설교를 글로 요약한다* 는 전제였습니다. 나눠야 합니다.

- **요약문은 영상이 될 수 없습니다.** NexusSum 이 만드는 건 새로 쓴 글이고,
  영상으로 만들려면 기계 음성이나 자막이 필요해 **목사님 목소리가 아니게 됩니다.**
- **그런데 길이 제어는 그대로 필요합니다.**
  1차 선정이 **221.6초** 로 목표 180초를 **23% 초과**했습니다.
  긴 조각을 줄이고 겹치는 조각 하나를 빼는 **압축 단계**를 거쳐야 184.5초가 됐습니다.
  NexusSum 이 다루는 문제가 정확히 이것입니다 (제로샷 길이 준수율 0.2~0.6).

→ **DIAMOND 의 구조에 NexusSum 의 길이 제어를 얹는** 모양. 두 논문 다 CJ 연구진 것이라 붙이기 어색하지 않습니다.

## 5. 남은 위험

1. **짜깁기로 들릴 수 있음.** 3분에 화제 전환 15번, 약 11초에 한 번.
   숏폼에선 흔한 밀도지만 설교는 호흡이 긴 말이라 다를 수 있음. **들어보고 판단할 것.**
   너무 잘면 → 5분으로 늘리거나, 네 포인트 중 하나만 깊이 담는 쪽으로.
2. **영상 한 편으로 확인한 것.** 이 설교가 번호를 붙여 선언하시는 구조라 쉬웠음.
   **매주 그러신지는 다른 영상이 있어야 앎.** 지난 설교 3~4편만 더 있으면 바로 확인됨.
3. 지난 검토에서 확인된 실무 조건들이 그대로 적용됨 — `marker.clips` 충돌, 전사 선행, API 키, 자막 오인식.

## 6. 권하는 만드는 순서

앞의 셋은 인터넷도 키도 없이 됩니다. **셋만으로도 오늘 만든 것과 같은 결과가 나옵니다** (고르기만 사람이 하면 됨).

1. **쉼 찾기 + 목차 찾기** (키 불필요)
   오디오에서 실제 쉼, 전사문에서 네 포인트 선언 문장. 둘 다 규칙으로. **모든 방식의 공통 바닥.**
2. **조각 목록 화면** (키 불필요)
   미리 듣고 빼고 밀 수 있는 화면. `marker.clips` 와 섞이지 않는 별도 필드에.
3. **이어붙여 내보내기 + 길이 맞추기** (키 불필요)
   목표 길이 초과 시 긴 조각부터 줄이는 단계까지. 페이드 0.25초.
   `core/cut.py` 에 자르기·음량·자막이 이미 있음. **여기까지가 완성된 기능.**
4. **고르는 일을 AI 에게** (키 필요)
   앞의 셋이 서 있으면 키가 없어도 사람이 고르면 그만 → 기능이 사라지지 않음.
