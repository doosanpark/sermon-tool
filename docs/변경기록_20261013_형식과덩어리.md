### 덩어리와 역할 — 형식과 무관한 바닥층

문단급 쉼(1.2초 이상) · 봉독 시작/끝 · 자막이 3초 넘게 빈 곳에서 잘라 20~60초 덩어리로 묶는다.
덩어리마다 역할을 매긴다: 문제 제기 / 핵심 / 예화 / 적용 / 봉독 / 안내 / 설명.

```
09-06 설교 → 덩어리 90개
  문제 제기 8 · 핵심 15 · 예화 1 · 적용 10 · 설명 46 · 성경 봉독 8 · 안내 2
```

**AI (뜻 + AI 로 고르기 일 때).** NexusSum 식으로 나눠 읽는다. 덩어리 8개(약 5분)씩
구획으로 묶어 구획마다 한 번 묻고(역할·혼자 들어도 되는지·인상), 구획 요약을 모아
한 번 더 물어 설교 주제와 문제 제기·핵심·적용 구획을 받는다. 09-06 기준 구획 11~12개,
구획당 입력 약 2천 자. 4B 모델은 36분을 한 번에 잘 못 읽지만 5분은 잘 읽는다.
**이 PC(CPU)에서 10분 안팎 걸릴 것으로 본다 — 아직 실제로 재지 못했다.**

## 5. 같은 날 덧붙인 것 — 자막 확인 · 고치기, 미리보기

자막에 틀린 낱말이 있어도 [3분 요약] 탭에서는 확인하고 고칠 방법이 없었다.

- **목록에서 바로 고치기.** 문장을 두 번 누르거나 [글자 고치기]. 고친 글은 자막 파일·[자막] 탭·
  설교 영상 자막·3분 요약 영상 자막에 모두 들어간다. 듣고 확인하려면 [이 문장 듣기].
- **같은 말도 고치기.** 낱말 하나를 고치면 "이 설교에 N번 더 있습니다 — 모두 고치고 다음부터도 고칠까요?"
  를 묻고, 고르면 `data/고칠말.txt` 에 넣는다. '창의진 → 창의진교회' 처럼 다시 돌리면 덧붙는 규칙은 넣지 않는다.
- **[▶ 요약 미리보기].** 고른 조각을 실제 영상 순서대로 이어서 튼다. 따로 뜨는 창에 영상과 **지금 자막**을
  큰 글씨로 보여 주고, 틀리면 그 창의 [이 자막 고치기] 로 바로 고친다. 재생기는 하나라 미리보기 동안만
  화면 출력을 그 창으로 옮긴다. 다른 곳을 누르거나 창을 닫으면 미리보기가 끝나고 화면이 돌아온다.
- 세로 1080x1920 영상 그대로의 모습은 [3분 요약 영상 만들기] 를 해야 볼 수 있다 (몇 분 걸린다).
- **확인 못 한 것:** 실제 재생(영상이 창에 나오는지)은 이 작업 환경에 소리·화면 장치가 없어 보지 못했다.
  다음 조각으로 건너뛰기·자막 표시·고치기·닫기 동작은 재생 위치를 흉내 내 확인했다.
