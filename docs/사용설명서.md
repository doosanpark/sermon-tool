# 창의진교회 설교영상 편집기 — 사용 설명서

예배 영상에서 **설교와 축도만 뽑아 하나의 영상으로** 만들어 주는 프로그램입니다.
목사님 목소리를 알아듣기 때문에, 대부분은 버튼 세 번이면 끝납니다.

---

## 1. 설치

### 압축 파일로 받으셨다면 (기본)

1. 받은 `SermonTool.zip` 을 **압축 풉니다**
2. 풀린 `SermonTool` **폴더를 통째로** 원하는 곳에 둡니다
   (예: `C:\SermonTool` 또는 바탕화면)
3. 폴더 안의 **`SermonTool.exe`** 를 두 번 클릭하면 실행됩니다

바탕화면에 아이콘을 두고 싶으면 `SermonTool.exe` 를 마우스 오른쪽 버튼으로 끌어다
바탕화면에 놓고 **[여기에 바로 가기 만들기]** 를 고르세요.

> **폴더째 두어야 합니다.** `SermonTool.exe` 파일 하나만 옮기면 실행되지 않습니다.
> 옆의 `_internal` 폴더에 필요한 것이 모두 들어 있습니다.

USB 에 폴더째 넣어 다른 컴퓨터에서 바로 쓸 수도 있습니다.

### 설치 파일(SermonToolSetup.exe)을 받으셨다면

실행하고 안내를 따르면 됩니다. 설치 중 바탕화면·시작 메뉴 바로가기를 선택할 수 있습니다.

### 공통

**따로 설치할 것은 없습니다.** 파이썬도, 영상 프로그램도 필요 없습니다.
유튜브에서 영상을 내려받을 때만 인터넷이 필요합니다.

**필요한 환경**: Windows 10 또는 11 (64비트). 32비트 Windows 에서는 동작하지 않습니다.

압축을 푸는 데 시간이 좀 걸립니다 (약 800MB). 영상을 다루는 프로그램(FFmpeg)이
안에 함께 들어 있기 때문입니다.

## 3. 쓰는 순서

### 가장 빠른 방법 — 자동으로 찾기

1. 유튜브 주소를 붙여넣고 **[영상 가져오기]**
   - 영상 크기에 따라 몇 분 걸립니다. 진행 상황이 로그에 나옵니다.
2. **[자동으로 찾기]**
   - 목사님 목소리를 대조해 설교와 축도를 찾습니다. **1~2분**이면 끝납니다.
   - 오른쪽에 시작·끝 시각이 채워집니다.
3. **설교 제목**을 적습니다 (파일 이름이 됩니다)
4. 시각이 맞는지 **[이 지점 확인]** 으로 들어 봅니다 (앞뒤 3초만 재생하고 멈춥니다)
5. 어긋나면 **`◀ 0.1` `0.1 ▶`** 버튼으로 다듬습니다
6. **[3. 설교 영상 만들기]**

### 직접 정하기

AI 를 쓰지 않고 눈으로 보고 정하는 방법입니다.

1. **[영상 가져오기]** 또는 **[내 컴퓨터에서 열기]**
2. **[직접 정하기]**
3. 영상을 재생하다가 설교가 시작되면 **[여기가 시작]**
4. 설교가 끝나면 **[여기가 끝]**
5. **[3. 설교 영상 만들기]**

### 내 컴퓨터에 있는 영상으로

**[내 컴퓨터에서 열기]** 로 영상 파일을 고르면, 유튜브 주소 없이도
자동으로 찾기와 직접 정하기가 모두 됩니다.

## 4. 결과물

```
%LOCALAPPDATA%\SermonTool\data\export\
```

주소창에 위 경로를 붙여넣으면 바로 열립니다.
내보내기가 끝나면 **[폴더 열기]** 버튼이 뜨니 그걸 누르는 편이 빠릅니다.

파일 이름은 **적어 둔 설교 제목**으로 만들어집니다.

```
20260824_하나님이 세상을 이처럼 사랑하사.mp4
```

제목을 비워 두면 날짜와 영상 번호로 저장되고, 만들기 직전에 한 번 물어봅니다.

만들어지는 영상은 **설교 + 축도**가 이어진 하나의 파일입니다.
사이의 찬양·헌금 순서는 빠집니다.

3분 요약을 만들면 이름 뒤에 `_3분요약` 이 붙어 같은 폴더에 저장됩니다.

```
20260824_하나님이 세상을 이처럼 사랑하사_3분요약.mp4    세로 영상
20260824_하나님이 세상을 이처럼 사랑하사_3분요약.mp3    소리만
```

## 5. 3분 요약 만들기 (숏폼)

36분짜리 설교에서 **핵심만 골라 3분으로** 줄여 줍니다.
유튜브 숏폼·인스타 릴스에 올리기 좋은 **세로 화면**으로 나옵니다.

### 먼저 자막이 있어야 합니다

요약은 설교 자막을 읽어서 고릅니다. **[자동으로 찾기]** 에서 자막까지 만들어
두셔야 합니다. 자막이 없으면 안내가 뜹니다.

### 순서

1. 아래 **[3분 요약]** 탭을 엽니다.
2. **[요약 골라줘]** 를 누릅니다. 프로그램이 밑그림을 만들어 줍니다.
3. 설교 문장이 쭉 나옵니다. **네모를 눌러 넣고 뺍니다.**
4. 위쪽 길이가 바로 바뀝니다. **3분에 맞으면 됩니다.**
5. **[3분 요약 영상 만들기]** 또는 **[3분 요약 mp3]** 를 누릅니다.

### 화면 보기

```
지금 3분 12초 · 문장 45개 · 목표보다 12초 깁니다      [====|==]

☑ [00:38:43] 첫 번째에요 문제보다 하나님이 먼저...      ← 진하게 = 설교 대목
☐ [00:38:48] 제가 읽습니다 5절 말씀 같이 보실까요?      ← 흐리게 = 성경 읽는 부분
☑ [00:40:04] 무너진 성벽 이야기가 먼저 나온 게...
☐ [00:40:28] 오늘 우리의 자리를 돌아 봅시다

고르는 방법 [뜻까지 보기 ▾]   준비됐습니다        [모델 받기]
[요약 골라줘] [되돌리기] [3분 요약 영상 만들기] [3분 요약 mp3]
```

- **네모를 누르면** 넣고 뺍니다
- **글을 누르면** 그 자리로 이동합니다
- **두 번 누르면** 그 대목을 들려줍니다
- **진하게** 나온 줄은 목사님이 "첫 번째에요" 처럼 번호로 말씀하신 대목입니다
- **흐리게** 나온 줄은 성경을 읽는 부분입니다. 요약에는 잘 안 맞습니다

초를 입력하거나 막대를 끌 일은 없습니다. **자를 자리는 프로그램이 목사님이
숨 고르는 자리로 알아서 맞춥니다.**

### 고르는 방법 세 가지

| 고르는 방법 | 무엇을 보나 | 받을 것 |
|---|---|---|
| 규칙만 (빠름) | 낱말 | 없음 — 바로 됩니다 |
| 뜻까지 보기 (권장) | 설교 전체를 대표하는 문장인가 | 120MB |
| 뜻 + AI 로 고르기 | 문맥까지 읽고 고름 | 120MB + 2GB |

모자란 것이 있으면 옆에 `아직 없음: … → [모델 받기]` 라고 뜹니다.
그 버튼을 누르면 **한 번만** 받습니다. 그 뒤로는 인터넷 없이 씁니다.

고른 방법은 기억되니, 다음에 켤 때 다시 고르지 않아도 됩니다.

### 영상과 mp3

- **영상** — 세로 1080×1920, 자막이 화면에 들어갑니다. 몇 분 걸립니다.
- **mp3** — 영상과 **똑같은 구간**을 소리만 뽑습니다. 몇 초면 끝나고 2MB 안팎입니다.

제목은 적어 두신 **설교 제목**이 화면 위와 mp3 제목에 들어갑니다.
그 아래 성경 본문(예: `느헤미야 1:5-11`)은 자막에서 찾아 자동으로 넣습니다.

### 마음에 안 들면

- **[다시 골라줘]** 를 누르면 처음부터 다시 고릅니다 (손댄 것은 사라집니다)
- **[되돌리기]** 는 방금 넣고 뺀 것을 되돌립니다
- 너무 잘게 끊긴다 싶으면 목표를 5분으로 늘릴 수 있습니다 (개발자에게 문의)

```

  ① 영상 가져오기          14:32:05
  화질 원본   https://www.youtube.com/watch?v=...
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 7. 알아 두면 좋은 것

### 되돌리기

구간을 잘못 건드렸다면 **[되돌리기]** 또는 `Ctrl+Z`.
AI 가 찾아 준 값으로 완전히 되돌리려면 **[AI가 찾은 구간으로]**.

### 이어서 작업하기

작업하던 구간과 제목은 자동으로 저장됩니다.
다음에 같은 영상을 열거나 **[이전 작업 불러오기]** 를 누르면 그대로 이어집니다.

### 축도 넣기

기본은 **설교만** 만듭니다. 축도까지 넣고 싶으면 [설교 영상 만들기] 버튼 바로 위의
**축도도 함께 넣기** 를 켜세요. 켜는 순간 AI가 찾아 둔 축도 구간이 구간 목록에
더해지고, 설교 뒤에 이어 붙습니다. 중간의 찬양·헌금은 어느 쪽이든 빠집니다.

한 번 정해 두면 다음에 켤 때도 그대로입니다. 축도를 못 찾은 영상에서 켜면
그렇다고 알려 드리고 저절로 다시 꺼집니다.

### 잡음 제거

**[고급 설정 보기]** 안의 **잡음 제거** 에서 고를 수 있습니다.
예배 방송에 섞인 웅웅거리는 잡음(마이크 험·에어컨 소리)을 줄입니다.

| 설정 | 효과 |
|---|---|
| 약하게 (기본) | 잡음이 눈에 띄게 줄고 목소리는 그대로 |
| 강하게 | 잡음이 심한 날에. 목소리가 조금 얇아질 수 있음 |
| 끔 | 원본 그대로 |

소리를 키우기 전에 잡음을 먼저 지우기 때문에, 잡음까지 같이 커지는 일이 없습니다.

### 소리 크기

예배 방송은 소리가 작게 녹음되는 경우가 많습니다. **[고급 설정 보기]** 안의
**소리 크기 맞추기** 가 켜져 있으면 방송 표준 음량에 맞춰 자동으로 키웁니다.

기본으로 켜져 있고, 40분 분량에 1분 정도 더 걸립니다. 소리가 깨지지 않는
선까지만 키우므로 그대로 두시면 됩니다.

### 정확히 자르기

**[고급 설정 보기]** 안의 **정확히 자르기** 를 켜면 지정한 시각 그대로 잘립니다.
대신 영상을 다시 만들어야 해서 40분 분량에 20~30분쯤 걸립니다.

꺼 두면 수 초 만에 끝나지만 컷 지점이 몇 초 밀릴 수 있습니다.
설교 시작·끝은 앞뒤로 여유가 있어 **보통은 꺼 두는 편이 낫습니다.**

10분이 넘는 분량을 정확히 자르기로 만들면 예상 시간을 먼저 알려 주고,
그 자리에서 빠른 쪽으로 바꿀 수 있습니다.

### 자막

**[자동으로 찾기]** 옆의 **자막도** 를 켜면 설교 내용을 받아써서 자막을 만듭니다.
20~40분 더 걸리고, 처음 한 번은 자막 모델을 인터넷에서 내려받습니다.

자막은 **영상 안에 들어갑니다.** 따로 자막 파일을 챙길 필요 없이 영상 하나만
보내면 됩니다. **[고급 설정 보기]** 안의 **자막 넣는 방법** 에서 둘 중 하나를
고르시면 됩니다. 한 번 고르면 다음에 켤 때도 그대로 유지됩니다.

| 설정 | 보는 사람이 | 걸리는 시간 |
|---|---|---|
| 껐다 켤 수 있게 (기본) | 자막을 켜고 끌 수 있습니다 | 몇 초 |
| 항상 보이게 | 자막을 끌 수 없습니다. 대신 어떤 재생기에서도 보입니다 | 40분 분량에 20~30분 |

**어느 것을 고를까요?** 평소에는 **껐다 켤 수 있게** 로 두시면 됩니다. 빠르고,
교회 컴퓨터·USB·유튜브 어디서나 잘 나옵니다.

**항상 보이게** 는 자막을 그림처럼 화면에 박아 넣습니다. 카카오톡·밴드로 보낸
영상을 휴대폰에서 바로 재생하면 자막을 읽지 못하는 경우가 가끔 있는데, 그럴 때
쓰시면 됩니다. 대신 화면을 전부 다시 그리느라 오래 걸리고, **한 번 태운 자막은
나중에 뺄 수 없습니다.**

자막을 화면에 태울 때는 흰 글씨에 반투명 검은 띠를 깔아 밝은 화면에서도
글자가 묻히지 않게 합니다.

**자막백업 폴더** — 어느 쪽을 고르든 .srt 자막 파일이 영상 폴더 안의
**자막백업** 폴더에 따로 남습니다. 유튜브에 올릴 때 자막 파일을 같이 올리거나,
나중에 자막을 고칠 때 쓰시면 됩니다. 영상 옆에 두지 않는 이유는, 같은 이름의
.srt가 영상 옆에 있으면 재생기가 그것까지 읽어 자막이 두 번 겹쳐 보이기
때문입니다. 안 쓰시면 그냥 두셔도 됩니다.

**받아쓰기가 틀린 곳 고치기**

컴퓨터가 받아쓴 자막은 몇 군데씩 틀리기 마련입니다. 화면 아래 **[자막] 탭**에서
바로 고칠 수 있습니다.

1. 자막 줄을 **한 번** 클릭 → 영상이 그 시각으로 이동합니다. 들어보세요.
2. 틀렸으면 그 줄을 **두 번** 클릭 → 그 자리에서 글자를 고치고 Enter.
3. 고친 내용은 자동으로 저장되고, [설교 영상 만들기]를 누르면 고친 자막이
   그대로 영상에 들어갑니다.

**'항상 보이게' 로 만들기 전에는 꼭 먼저 고치세요.** 화면에 태운 자막은 지우거나
고칠 수 없습니다. '껐다 켤 수 있게' 는 나중에 다시 만들면 됩니다.

### 설교 mp3 만들기 (소리만)

[설교 영상 만들기] 옆의 **[설교 mp3]** 를 누르면 영상 없이 **소리만** mp3로
뽑습니다. 구간 목록에 있는 그대로 들어갑니다 — 축도를 켜 두었으면 축도까지
들어갑니다.

- 40분 분량이 **1분 안쪽**이면 끝납니다 (영상 만들기보다 훨씬 빠릅니다)
- 파일이 작습니다 (40분에 30MB 안팎) — 카카오톡으로 보내기 좋습니다
- 설교 제목이 mp3 제목으로 들어가서, 휴대폰 음악 앱에서 제목이 그대로 보입니다
- 차에서 듣거나, 눈이 불편하신 분께 보내 드릴 때 쓰시면 됩니다

영상을 먼저 열어 두어야 합니다. 시작 영상은 mp3에는 넣지 않습니다.

### 시작 영상 (교회 로고 등)

설교 영상 앞에 짧은 영상을 붙일 수 있습니다. **[고급 설정 보기]** 안의
**시작 영상** 에서 [고르기] 로 파일을 하나 고르면 됩니다. 한 번 고르면 계속
쓰이고, [빼기] 를 누르면 다시 안 붙습니다.

- 크기나 화질이 본 영상과 달라도 **자동으로 맞춰** 붙입니다
  (비율은 지키고, 남는 자리는 검게 채웁니다)
- 소리가 없는 영상이면 무음으로 넣습니다
- 자막 시간도 붙인 만큼 자동으로 밀립니다
- 본 영상은 다시 만들지 않으므로 몇 초면 끝납니다

## 8. 문제가 생기면

### 처음 켰을 때 [자동으로 찾기] 가 눌리지 않습니다

[진행 로그] 탭 맨 위에 이유가 적혀 있습니다.

```
  [OK ] 성문 검출 엔진
  [없음] 목사님 성문
  → [자동으로 찾기] 를 쓸 수 없습니다: 목사님 성문
```

압축을 풀 때 `SermonTool` 폴더가 통째로 풀렸는지, `_internal` 폴더가 함께 있는지 확인하세요.

### "이 파일에는 소리가 없습니다"

영상을 내려받다 중간에 끊긴 경우입니다.
그 파일을 지우고 **[영상 가져오기]** 로 다시 받으세요.

### 자동으로 찾기가 이상한 구간을 잡습니다

목사님이 바뀌었거나 음향 장비가 크게 달라진 경우입니다.
**[직접 정하기]** 로 하시거나, 관리자에게 성문 재등록을 요청하세요.

### 영상 내려받기가 실패합니다

유튜브가 바뀌면 가끔 생깁니다. 로그 탭에 어떤 포맷을 시도했는지 남습니다.
관리자에게 `yt-dlp` 갱신을 요청하세요.

### 자막 만들기가 멈춘 것 같습니다

멈춘 게 아닙니다. 설교 35분 자막은 **20~60분**이 걸립니다.
진행 로그에 이런 줄이 흐르면 잘 돌고 있는 것입니다.

```
[자막]  26%  9:00 / 35:12   0.8배속   남은 시간 약 32:40
```

이 줄이 몇 분째 안 움직이면 그때 알려 주세요.
작업이 도는 동안에는 구간을 만질 수 없게 잠깁니다 — 만져도 결과에 반영되지
않고 사라지기 때문입니다.

### 3분 요약에 자막이 안 나오는 대목이 있습니다

일부러 그렇게 해 두었습니다.

조각을 이어붙일 때 말이 잘리지 않도록 앞뒤로 조금씩 여유를 두는데, 그 여유에
앞뒤 문장의 꼬리가 걸립니다. 그것까지 자막으로 넣으면 **0.2초씩 번쩍이다 사라져**
눈이 아픕니다. 그래서 너무 짧게 스치는 자막은 넣지 않습니다.

소리의 **열에 아홉**은 자막이 붙고, 나머지는 조각이 바뀌는 앞뒤 한두 마디입니다.

### AI 로 고르기가 오래 걸립니다

`[AI] 120초  340자 …` 같은 줄이 흐르면 잘 돌고 있는 것입니다.
보통 **1~3분**이면 끝납니다. 8분이 지나면 스스로 포기하고, 규칙과 임베딩이
고른 결과를 그대로 씁니다 — 결과가 안 나오는 일은 없습니다.

이 PC 에 AI 가 버겁다 싶으면 **[고르는 방법]** 을 `뜻까지 보기` 로 두세요.
몇 초에 끝나고 결과도 나쁘지 않습니다.

프로그램을 강제로 닫으셨다면 작업 관리자에 `llama-server.exe` 가 남아 있을 수
있습니다. 있으면 [작업 끝내기] 로 정리해 주세요.

### 그 밖의 오류

**[진행 로그]** 탭의 마지막 부분을 관리자에게 보여 주세요.
무엇을 하다 멈췄는지 그대로 적혀 있습니다.
