# 새 PC 에서 빌드하기

GitHub 에는 소스만 있습니다. 성문 · 고칠말 · 학습한 AI 모델은 `dist\배포자료\` 폴더에 따로 모이고,
그 폴더의 `시작하기.bat` 이 GitHub 코드와 합쳐 줍니다.

## 건네는 쪽 (원래 PC)

`build_all.bat` 이 끝나면 `dist\배포자료\` 가 자동으로 만들어집니다.
빌드 없이 자료만 모으려면 `배포자료_만들기.bat` 을 두 번 누르세요.

| 들어 있는 것 | 설명 |
|---|---|
| `voiceprint.npz` | 목사님 성문 — 없으면 설치본에서 자동 구간 찾기가 안 됩니다 |
| `고칠말.txt` | 오인식 사전 |
| `llm\sermon-….gguf` | 이 교회 설교로 학습한 AI 모델 (약 2.5GB) |
| `text-embed\` | 뜻 보기 모델 |
| `시작하기.bat` | 코드를 받아 합치는 파일 |
| `읽어주세요.txt` | 받는 분께 드리는 안내 |

이 폴더를 통째로 (USB나 개인 공유 링크로) 건넵니다.
성문은 사람의 목소리 정보이므로 GitHub 등 공개된 곳에는 올리지 않습니다.

## 받는 쪽 (새 PC)

1. Python 3.12 정식판, Git, Inno Setup 6 을 설치합니다.
   `winget install -e --id Python.Python.3.12` · `winget install -e --id Git.Git`
2. 받은 `배포자료` 폴더를 아무 곳에나 복사합니다. 예: `D:\work\배포자료`
3. 그 안의 `시작하기.bat` 을 두 번 누릅니다.
   - 옆(`D:\work\sermon-tool`)에 GitHub 코드를 받습니다. 이미 있으면 최신으로 고칩니다.
   - 패키지를 설치하고 ffmpeg · yt-dlp · deno 를 내려받습니다.
   - 배포자료의 자료를 코드 폴더에 합칩니다 (모델을 또 복사하지 않고 그 자리에서 읽습니다).
   - 끝에 "지금 빌드할까요" 를 묻습니다.
4. 빌드가 끝나면 `sermon-tool\dist\SermonTool_v버전.zip` 이 나옵니다.

## 깃에 올리지 않는 것

| 파일 | 이유 |
|---|---|
| `bin\*.exe` | 크고, 공식 배포처에서 받으면 된다 |
| AI 모델 gguf, safetensors | GitHub 는 한 파일 100MB 를 넘으면 거절한다 |
| `data\voiceprint.npz` | 사람의 목소리 정보라 공개 저장소에 올리지 않는다 |
| `dist\`, `배포자료\` | 위 파일들을 모아 둔 곳 |
